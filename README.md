# Reversi

**C# · Windows Forms · board game**  
**Course:** Utrecht University · Modeling & Programming

## Overview

Original C# implementation of the Reversi board game.

## Project files

- `Reversi/` — original Visual Studio source and resources.
- `Reversi.sln` — Visual Studio solution.

## Running the project

Open the `.sln` file in Visual Studio on Windows with the .NET desktop development workload. These files were developed as coursework and have not been rebuilt in the current environment.

## Provenance

This repository preserves **original university coursework source files**. The interactive browser adaptations in the portfolio were built later and may use different implementations. No current build or hardware compatibility is guaranteed.
